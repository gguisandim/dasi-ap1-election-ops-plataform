# Diário — integração MCP da Central de Tarefas

**Atividade executada:** 2026-10-20  
**SPEC:** [SPEC/2026-10-20-mcp-task-server.md](../SPEC/2026-10-20-mcp-task-server.md)

## Implementação registrada

- Servidor MCP TypeScript com transporte stdio e SDK oficial.
- Tools `listar_tarefas`, `consultar_tarefa`, `criar_tarefa` e `atualizar_tarefa`, usando exclusivamente `GET /api/tasks`, `GET /api/tasks/:id`, `POST /api/tasks` e `PATCH /api/tasks/:id`.
- Validação local alinhada aos filtros e DTOs do controller da Central; autenticação Bearer encaminhada à API.
- Resultados estruturados e tratamento de HTTP 400, 401, 403, 404, 422 e falhas de conexão.
- Configuração do workspace em `.vscode/mcp.json`, com credenciais carregadas de `.env.mcp` ignorado pelo Git.
- Hints MCP distinguem leitura e escrita. O VS Code configura aprovação por tool em **Chat: Manage Tool Approval**, não em `.vscode/mcp.json`: aprovar automaticamente somente as duas tools de leitura e manter aprovação manual para as duas de escrita.
- Testes cobrem descoberta das quatro tools, validação, requisições, token, erros HTTP e falha de conexão.
