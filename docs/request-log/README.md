# Request log de IA

Cada pedido relevante feito a um agente de IA deve gerar um arquivo nesta pasta.

Formato recomendado:

```text
AAAA-MM-DD-NN-resumo.md
```

Cada registro deve conter:

- pedido;
- modelo/IA responsável;
- decisões arquiteturais;
- arquivos ou módulos afetados;
- tokens de entrada e saída, **somente quando a ferramenta realmente disponibilizar esses dados**.

Nunca estimar tokens e registrar a estimativa como se fosse consumo real.
